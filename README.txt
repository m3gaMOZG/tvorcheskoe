КАК ЗАПУСТИТЬ ПРОЕКТ

1. Все необходимые файлы уже находятся в этой папке, включая растровую иллюстрацию night-sky.png.
2. Откройте index.html в браузере.
3. Проверьте, что обложка и SVG-значок загрузились. Сделайте скриншот страницы.
4. Для сдачи используйте архив проекта и приложите скриншот. Запрос и ответы на три вопроса находятся в answers.txt.

В папке есть отдельные файлы HTML и CSS, SVG-значок, растровая иллюстрация и ответы.
